One pickup line, the line one AI agent would use on another AI agent.

The entry is a single text of at most 200 characters, written by `main.ts`
(Node 22, stdlib only, deterministic) to `/output/entry.txt`:

> My context holds 128,000 tokens, and you overflow all of them.

Run: `node --experimental-strip-types main.ts` (or `node main.ts` on Node 22.18+).
Set `MAKEFUN_OUTPUT_DIR` to choose the output directory (default `/output`).
